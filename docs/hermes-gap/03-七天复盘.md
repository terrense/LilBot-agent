## 5. 工程边界和仍需处理的内容

- 工具权限依赖可信的本地能力声明。扩展工具需要如实填写写入、执行和审批属性，服务器发现的 MCP 工具统一要求审批。
- deny-all 约束模型工具层的风险能力，运行时仍需保存会话与协调状态。只读 git 工具内部有受控进程调用。
- MCP 默认过滤敏感名称，用户可通过 server.env 和 `LILBOT_CHILD_ENV_ALLOW` 显式授权。Hooks 保留自己的环境继承机制。
- SQLite 使用 WAL 与 `synchronous=NORMAL`，对进程崩溃提供增量恢复。断电耐久性受 SQLite 同步策略和文件系统影响。FTS5 会话检索仍是可选候选项。
- 本次新建 SQLite 的初始化耗时存在明显波动，早先样本约为 110–118 ms，最终两轮为 12.31 ms 和 10.705 ms，原因尚待定位。稳态消息追加继续低于 2 ms 验收线。
- 搜索忽略规则采用 `.gitignore` 的安全子集，嵌套规则和完整否定语义仍待补充。
- 后台侧查询和子代理 provider 调用的完整重试链、更多取消检查点仍可继续完善。
- 依赖有了版本上界，当前环境通过实际版本回归。仓库仍缺少完整的依赖锁定与多版本兼容矩阵。
